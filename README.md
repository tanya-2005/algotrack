# 📖 About

**AlgoTrack** is an all-in-one productivity platform built for students preparing for coding interviews and competitive programming.

Instead of only counting solved questions, AlgoTrack helps users:

- 📚 Organize DSA practice
- 🧠 Reflect on mistakes
- 🔁 Schedule revisions
- 📈 Track learning progress
- 🎯 Build long-term problem-solving skills

# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/tanya-2005/algotrack.git
```

Go inside project

```bash
cd algotrack/frontend
```

Install dependencies

```bash
npm install
```

Start development server

```bash
npm run dev
```

---

# ⚙️ Environment Variables

Create a `.env` file.

```env
VITE_SUPABASE_URL=your_supabase_url

VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
```

# 💡 Why AlgoTrack?

Most coding platforms answer one question:

> **"How many problems have you solved?"**

AlgoTrack answers something more important:

> **"What have you actually learned?"**

By combining progress tracking, reflections, revision planning, and organized notes, AlgoTrack transforms DSA preparation into a structured learning experience instead of a simple question counter.
